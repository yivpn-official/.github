# YIVPN (易VPN)

**Private Zero-Logs VPN for Windows, macOS & Android** · *Native MCP for AI Agents* · *iOS Coming Soon*

- **90 Minutes Free Every Day** — No account registration, email address, or credit card required.
- **Built-In Local MCP Server (Windows & macOS)** — Connect Claude Code, OpenAI Codex, or Cursor to loopback `127.0.0.1:38419/mcp` to inspect VPN state, diagnose routes, and safely preview, apply, and roll back `sing-box` split-tunnel rules.
- **Modern Encrypted Transport** — Built on `sing-box 1.14.3` (`Hysteria2` QUIC & `VLESS+REALITY` TLS 1.3) with volatile RAM-only packet forwarding.
- **Smart Split Tunneling** — Keep local banking, LAN devices, and domestic apps at native direct ISP speed while encrypting external traffic.
- **Honest Pricing** — From **$2.99/mo** (or **$21.99/yr** = **$1.83/mo**) for up to **5 simultaneous devices**.
